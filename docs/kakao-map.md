# 상세 화면의 카카오맵

결과 카드와 상세 화면의 지도 버튼은 선택한 구·동과 업종을 카카오맵 검색 URL로 연결한다. 이 기능은 키 없이 사용할 수 있다.

상세 화면 안에 지도·검색 점포 마커·점포 목록을 표시하려면 프로젝트 루트 `.env`에 아래 값을 설정한다.

```dotenv
KAKAO_JAVASCRIPT_KEY=카카오_앱의_JavaScript_키
```

카카오 개발자 콘솔에서 해당 JavaScript 키의 SDK 도메인에 실제 접속 주소를 등록한다. 현재 로컬 설정은 `http://localhost:3000`이다. 배포 주소도 사용하면 그 도메인을 함께 등록한다. 설정 후 백엔드를 다시 시작하고 브라우저를 새로고침한다. REST API 키나 Admin 키를 사용하는 설정이 아니다.

백엔드 `/api/map-config`는 브라우저용 JavaScript 키만 반환한다. 지도 SDK는 상세 화면을 열 때 지연 로딩하며, 키가 없거나 카카오 서비스가 응답하지 않으면 같은 지역·업종으로 검색할 수 있는 카카오맵 링크를 제공한다. 지도 위치와 점포를 예시 이미지로 대신하지 않는다.

지도는 Kakao Places의 키워드 검색 결과를 표시한다. 마커 또는 목록 항목을 누르면 점포명·주소·카카오맵 상세 링크를 볼 수 있다. 검색 결과는 페이지당 15개이며 카카오 API가 제공하는 페이지 이동을 사용한다. 지도 점포 수는 DB의 업종 코드별 전체 점포 수와 다른 검색 결과이므로 동일한 전체 건수로 표현하지 않는다. 실제로 측정한 밀집 구역이나 행정동 경계가 없으므로 예시 원형 경계를 그리지 않는다.

디자인은 Figma `py4U7Xy5Eens5Ut0XGVFXS`, `6:6091`을 참고한다. 상단 개업·폐업은 하나의 카드로 묶고, 하단은 추천 이유·그래프와 380px 경쟁 점포 사이드바로 구성한다. 기존에 제거한 기술 설명과 예시 수치는 복원하지 않는다. 그래프는 시간 순서를 유지하면서 상세 화면 진입 시 오른쪽 끝의 최신 구간으로 스크롤한다.

기존 `detail-bookmark.svg`(16×16), `detail-shop.svg`(7×7)는 Figma와 같은 슬롯의 자산을 재사용했다. 실제 지도 부분은 정적 다이어그램을 사용하지 않는다.

검증 제약: 현재 `.env`에는 카카오 JavaScript 키가 없다. SDK 로딩과 URL 구성은 모의 테스트로 확인했지만 실제 카카오 지도 타일·점포 검색은 검증하지 못했다. 브라우저 보안 정책이 로컬 미리보기 파일 접근을 차단해 데스크톱·모바일 스크린샷 비교도 완료하지 못했다.
