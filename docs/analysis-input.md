# 상권 분석 입력

- 기본은 자연어 입력이며, 조건 선택 탭에서 업종·희망 지역·경쟁 강도·안정성·성장성을 선택한다. 각 모드의 입력은 탭 전환 후에도 유지된다.
- 로고는 Figma `10:129`에서 직접 내보낸 `frontend/public/figma-assets/binsight-logo.svg`를 사용한다. 로고와 서비스 이름은 `#analysis`로 이동하고 기존 결과를 초기화하는 하나의 링크다.
- `GET /api/analysis-options`는 기존 `loadRecommendationData`로 실제 DB 목록을 읽고 업종명·코드와 구·군·행정동만 반환한다. 서버와 프론트엔드에서 5분간 캐시하며, 실패한 요청은 캐시하지 않는다. AI·이력 분석은 호출하지 않는다.
- 지역 목록은 부산 전체, 구·군, 구·군을 포함한 행정동 이름을 제공한다. 동명이 같은 행정동을 구분할 수 있다.
- 업종은 실제 DB 코드로 선택값을 관리한다. 이름이 유일하면 기존 화면과 호환되는 업종명을 분석에 전달하고, 동명 업종은 정확한 코드를 전달한다. 기존 업종 해석기는 DB에 존재하는 코드만 받아들인다.
- 경쟁 강도는 보통=`normal`, 낮은 곳 선호=`low`, 상관없음=`any`이다. 안정성·성장성은 보통=`normal`, 중요=`important`이다.
- `POST /api/analyze`는 기존 자연어 요청과 `{conditions: {...}}` 요청을 모두 지원한다. 조건 선택 요청은 AI 재해석을 거치지 않고 기존 검증·분석·결과 구조를 사용한다.
- 검색 콤보박스는 문자 필터, 목록 선택, 선택 해제, 방향키·Enter·Escape, 바깥 클릭, 한국어 IME를 지원한다. 입력 중인 검색어는 목록에서 선택하기 전까지 기존 선택값을 대체하지 않는다.

추가 패키지, 환경변수, DB 마이그레이션은 필요하지 않다. 기존 `DATABASE_URL`이 정상 연결되어야 실제 목록·분석을 조회할 수 있다.

검증: `npm test`, `npm run build`. 실행 중인 서버는 재시작하고 페이지를 새로고침하면 변경된 정적 빌드가 반영된다.
