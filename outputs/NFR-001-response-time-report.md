## 환경과 방법

- 대상: 이미 실행 중인 http://localhost:3000/ B-Insight 서비스.
- 브라우저: ChatGPT 내장 브라우저. 로그인하지 않은 상태.
- 소스 참고: 측정 당시 체크아웃 HEAD 14adc43, 브랜치 fix/industry-mapping-mobile-layout. 실행 서버와 제공 중인 빌드의 커밋 일치 여부는 별도로 검증하지 않았다.
- 자연어 분석 6종을 동일한 순서로 5회씩, 동시에 요청하지 않고 순차 실행했다.
- 사전 점검 분석 1회는 통계에서 제외했다. 따라서 서버 최초 기동 및 최초 요청의 지연을 평가한 결과가 아니다. 서버/DB/모델의 캐시를 초기화하지 않았다.
- 각 회차에서 ‘조건 다시 입력’으로 돌아가 자연어를 입력했다. 입력 시간과 화면으로 돌아가는 시간은 통계에서 제외했다.
- 자동화 코드에서 Date.now()를 기록하고 ‘AI 상권 분석하기’ 클릭을 요청한 뒤, ‘추천 창업 상권’ 제목이 visible 상태가 될 때까지 기다린 직후 시간을 기록했다.
- 이어서 매 회차 DOM 스냅샷에서 ‘상세 보기’가 존재하는지 확인했다. 30회 모두 추천 카드가 있는 결과 화면으로 전환되었다.
- 측정값에는 클릭 명령 전달과 가시성 확인에 드는 자동화 오버헤드가 포함된다. 브라우저 내부의 실제 클릭 이벤트부터 최종 픽셀 페인트까지를 정밀 계측한 수치는 아니다.
- 분석 API 처리, 네트워크 왕복, React 결과 표시를 포함하는 사용자 흐름을 측정했다. API만의 응답시간은 별도로 측정하지 않았다.
- 동시 접속 부하, 모바일 기기, 운영 서버와 외부 사용자 네트워크 조건은 포함하지 않았다. 운영 환경 전체의 성능 보장으로 일반화하지 않는다.

## 테스트 보고서 기입 문장

로컬 단일 사용자 환경에서 자연어 분석 입력 6종을 각 5회씩 총 30회 순차 실행한 결과, 분석 버튼 클릭 요청부터 추천 결과 제목의 표시 확인까지 평균 4.279초(최대 9.774초)가 소요되었다. 30회 모두 추천 결과가 정상 표시되었으며, 해당 측정 조건에서 NFR-001의 평균 응답시간 10초 이하 목표를 충족하였다. 사전 점검 1회 이후 캐시를 초기화하지 않은 반복 실행 결과이며 자동화 오버헤드가 포함된다.
